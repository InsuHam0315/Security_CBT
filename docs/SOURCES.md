# 자료 목록과 슬라이드별 출처 지도

Lecture 폴더와 하위 폴더에서 확인한 학습 파일은 아래 PPTX 4개입니다. 강의계획서·시험 공지·별도 코드·PDF는 발견되지 않았습니다. 시험 대비 범위는 사용자가 1~4장 전체로 확인했습니다.

| ID | 로컬 자료 이름 | 실제 표시 슬라이드 수 | 분석 |
|---|---|---:|---|
| P1 | 01장 정보 보안의 세계.pptx | 40 | 텍스트·표·그림·코드 렌더링 확인 |

총 248장. 3·4장은 일반 PowerPoint 열기에서 오류가 있어 읽기 전용 복구 열기로 렌더링했습니다. 원본은 수정하지 않았습니다. 분석용 PDF와 이미지는 저장소 밖에 보관하며 공개하지 않습니다. 읽지 못한 자료는 없습니다.

아래 번호는 표지를 포함한 1부터 시작하는 **PPTX의 실제 표시 순서**입니다. presentation.xml의 관계 순서로 계산했으며 내부 slideN.xml 번호나 교재 쪽수와 같다고 가정하지 않습니다. 콘텐츠 출처 버튼에서도 같은 번호를 표시합니다.

`—`는 분석했지만 해당 슬라이드를 직접 근거로 연결한 콘텐츠가 없다는 뜻입니다. 원문을 추출·재게시하는 표가 아닙니다.
