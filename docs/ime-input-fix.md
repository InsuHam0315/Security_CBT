# 한글 답안 조합 수정 · 2026-10-18

장 강의의 ‘이 장 문제 연습’에서 시작한 단답 입력으로 재현했다. Chromium의 실제 composition 입력을 `ㅇ → 우 → 워 → 웜` 순서로 보내면 이전 버전은 두 번째 단계에서 `우` 대신 `ㅇ우`를 만들었다. 답안 칸의 controlled value가 비동기 IndexedDB 저장 후 돌아오는 프로필만 사용하여, 입력 직후의 이전 값 복원이 IME 조합을 끊었다.

`AnswerInput`이 입력 이벤트 안에서 화면의 문자열을 즉시 갱신한다. 비동기 저장·프로필 알림·타이머 갱신이 조합 문자열을 덮지 못하게 하고, 입력 포커스·조합·저장 대기 상태를 구별한다. 문항·응시·사용자 ID로 입력 컴포넌트를 구분해 다음 문제에 이전 답이 남지 않게 한다. 기존 저장 구조·문항·정답은 유지한다. 단답·서술·숫자 입력이 같은 처리를 사용한다.

React는 controlled input의 backing value를 onChange에서 동기적으로 갱신하도록 설명한다. [React input 문서](https://react.dev/reference/react-dom/components/input#my-input-caret-jumps-to-the-beginning-on-every-keystroke)를 근거로 비동기 영속 저장과 화면 입력 상태를 분리했다.

검증은 개인 브라우저 프로필을 열지 않는 임시 Edge/Chromium 컨텍스트에서 수행한다. `npm run test:ime`는 CDP `Input.imeSetComposition`과 `Input.insertText`를 사용해 실제 브라우저의 조합 이벤트를 발생시킨다. 단순히 완성된 한글을 input.value에 넣는 검사가 아니다. 운영체제의 모든 IME 종류를 전수 검사했다는 의미는 아니다.

- 390·1440px에서 총 48개 조합 단계 확인: `ㅇ/우/워/웜`, `SQL 인젝션`, 서술 답의 한글 조합, 조합 중 되지우기.
- 조합 중 1초 이상의 타이머 갱신, 빠른 영문·숫자 입력, 선택 삭제, Enter 줄바꿈, blur 확인.
- 장 링크 → 복습 시작 → 입력 → 다른 문항 → 복귀, 저장 완료 뒤 새로고침, 정답 확인, 전체 제출 후 백업의 실제 문자열 확인.
- 연습·시험 모드, 숫자 답안의 소수 입력·저장 확인.
- 기존 17개 자동 테스트와 출처·정답·빌드, 320·390·768·1440px 각 76개 경로 및 진도·메뉴·백업 검사 통과.

‘저장 중’에는 비동기 기록 작업이 진행되며, 새로고침 복원 검사는 ‘저장 상태 확인됨’ 이후 수행한다. 답안 화면은 저장 완료를 기다리지 않고 입력을 즉시 표시한다. 테스트의 기록·백업·화면은 임시 프로필의 가상 데이터이며 개인 학습 기록을 수정하지 않는다.
