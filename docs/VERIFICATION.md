- Chrome 실제 화면에서 장 전체 본문, 슬라이드 표시, DB 감사 등 복원 내용, 메뉴 전체 접기·펼치기를 확인했습니다. 개인 계정이나 기존 공개 사이트의 학습 기록은 수정하지 않았습니다.

## 2026-10-17 HTTPS·로컬 계정 재검증

가상 검증 계정으로 production 미리보기(127.0.0.1:4175)에서 가입, 로그아웃, 잘못된 비밀번호 거부, 재로그인, 새로고침 후 세션 복원을 실제 Chrome 화면에서 확인했습니다. 콘솔 오류·경고 0개. 실제 개인 계정과 학습 기록은 변경하지 않았습니다. HTTP/암호화 API 미지원 상황에서 가입·로그인을 먼저 차단하는 회귀 테스트 2개를 추가했고 총 13개 테스트, 콘텐츠 검사와 TypeScript·빌드가 통과했습니다.

공개 도메인의 CNAME·A·AAAA·CAA와 Pages DNS 검사는 정상입니다. 동일 도메인 연결을 잠시 해제했다가 복구해 인증서를 재요청했지만 GitHub가 `bad_authz`를 다시 반환했습니다. 따라서 위 계정 UI 검증은 로컬의 신뢰할 수 있는 출처에서 수행한 결과이며, 공개 HTTPS에서 검증한 결과와 구분해야 합니다. 인증서 확인에 실패한 연결을 우회하지 않습니다.

앱 내 브라우저의 viewport 변경이 실제 DOM 폭에 적용되지 않아 모바일 검증은 별도의 **격리된 headless Edge**로 진행했습니다. 기존 Edge/Chrome 개인 프로필은 열지 않았습니다.

`npm run test:browser`: 320·390·768·1440px × 100경로 = **400경로 검사**, 각 폭에서 가로 넘침 0px, 콘솔/페이지/HTTP 오류 0. 화면 캡처도 눈으로 확인했습니다.

- 320·390px 메뉴의 Escape·배경·페이지 이동 닫기, 포커스 순환·복귀
- 9그룹 독립 토글, Space 키 토글, 각 경로 실제 본문 표시
- 로그인 → 회원가입 → 로그인 세부 메뉴의 선택 화면 갱신
- W3C 표 내림차순 정렬, 403 필터 한 행, 확대와 Escape 닫기
- SQL 사례 2줄 해설, 라이트 테마 저장 후 새로고침 복원
- 잘못된 JSON 거부·적용 버튼 없음, 검증 미리보기, 합치기 및 덮어쓰기 후 강의 진도 확인

검증 중 발견한 모바일 닫힌 메뉴의 키보드 접근, 같은 부모 경로의 회원가입 화면 전환, 유효 백업 선택 후 남던 이전 오류 표시를 수정했습니다. 비동기 저장·React 렌더링 완료를 기다리도록 테스트를 보정했습니다. 최종 검사 결과는 `test-results/browser-report.json`에 남으며 가상 데이터와 화면 캡처는 공개 저장소에 올리지 않습니다.

첫 Linux Actions 브라우저 실행에서 320px SL06의 긴 계정·경로 설명이 33px 넘치는 현상을 발견했습니다. 플랫폼별 글꼴 폭 차이를 수용하도록 본문의 긴 문자열 줄바꿈과 강의 카드 최소 폭을 수정했습니다. 배포는 재검사 통과 후 진행합니다.

수정 후 Linux Chromium에서도 4개 폭·400경로·자료·백업 검사가 통과했습니다. Pages 환경의 초기 main 전용 배포 규칙 때문에 작업 브랜치의 첫 배포가 거부되어 요청한 `codex/computer-security-cbt`를 허용 목록에 추가했습니다.

## 미확인 사항

- 교재 4판 1~4장 연습문제 원문·번호·정답은 책과 직접 대조하지 못했습니다. 제3자 게시물의 판본 및 정확성은 별도 확인이 필요합니다.
