# 컴퓨터보안 학습실

정보 보안 개론 1~4장 강의를 읽고, 가상 로그·설정·메시지·공격 상황의 증거로 답을 판단하는 시험 대비 정적 웹앱입니다.

- 공개 사이트: https://insuham0315.github.io/Security_CBT/
- 저장소: https://github.com/InsuHam0315/Security_CBT
- 작업 브랜치: `codex/computer-security-cbt`
- 4장(장마다 한 페이지, 기존 24단원 기록 보존) · 32사례 · 160고유 문항 · 종합 5회차(각 50문항·75분)
- 객관식 64 · 숫자 입력 29 · 짧은 답 35 · 서술 자기 평가 32

1~4장은 사용자에게 확인받은 대비 범위입니다. 시험 공지나 교수자의 실제 시험 규격은 확인되지 않았습니다. 5회차의 250개 출제 슬롯에는 90번의 재사용이 있습니다. 동일 회차 안에는 중복이 없으며 고유 문항 수는 160개입니다.

교수자가 교재 연습문제에서 출제한다는 사용자 설명을 반영해 **번호 제한 없이 1~4장 전체 연습문제 복습** 화면을 마련했습니다. 공개 게시물 링크는 교재와 대조할 보조 자료입니다. 교재 원문과 공식 해답을 검증한 문제 은행으로 표시하지 않습니다. 기존 160문항은 직접 작성한 강의 기반 예상문제입니다.

2026-10-20에 제공 자료 27개를 확인한 **별도 족보 문제집**(`/past-exams`)을 추가했습니다. 기출 복원 50개·정리자료 재구성 52개로 고유 102문항, 시험·교재 정리별 11세트입니다. 중복 사본·회차 간 같은 문항은 합쳐 출처 번호를 보존합니다. 사용자 요청으로 OWASP 구판 문항을 제외하고 2025 최종판 기준으로 수정한 보충문항을 수록했습니다. 학생 답·메모의 오류를 검토해 수정 이유와 공식 기술 자료 링크를 표시하며, 조건이 없는 원문·소감 문항 등 18건의 처리 기록은 점수에서 분리합니다. 기말·교재 6~10장도 포함하므로 기존 PPT 1~4장 범위와 구분됩니다. 원본 HWP·사진·ZIP·TXT·학생 개인정보는 공개하지 않습니다.

## 실행

Node.js 24, Python 3를 사용합니다.

```sh
npm ci
npm run dev
```

개발 주소: `http://127.0.0.1:5175/Security_CBT/`

```sh
npm run validate
npm run verify:content
npm test
npm run build
npm run preview
npm run test:past
```

배포 빌드 미리보기: `http://127.0.0.1:4175/Security_CBT/`

커스텀 도메인의 인증서 발급 오류로 2026-10-17에 GitHub 기본 HTTPS 주소로 임시 복구했습니다. Vite base는 `/Security_CBT/`입니다. 추후 커스텀 도메인 루트용 빌드는 환경 변수 `VITE_BASE_PATH=/`로 지정하고, 브라우저 검사 주소도 `CBT_BASE`로 맞춥니다.

미리보기를 별도 터미널에서 실행한 상태로 `npm run test:browser`를 실행합니다. Windows에서는 설치된 Edge를 사용하고, 다른 환경에서는 `npx playwright install --with-deps chromium`으로 테스트용 Chromium을 설치합니다. 기존 브라우저 프로필을 열지 않는 임시 컨텍스트에서 검사합니다.

## 학습 기능

- 1~4장 각각 한 페이지에 PPT 순서의 본문 147절·슬라이드 번호·표/코드 흐름 설명
- 추가 해설·정정과 직접 만든 가상 사례·자가 점검을 별도 영역에 표시. PPT 이미지는 추가하지 않음
- 사례 표의 검색·정렬·확대, 코드 줄별 해설, 단계별 메시지 흐름
- 고정 종합 회차의 연습/시험, 별도 집중 복습, 답안·선지 순서·검토 표시 저장
- 연습은 답안 확인 후, 시험은 제출 후 정답과 해설 공개
- 종료 시각을 저장하는 시험 타이머와 한 번만 처리하는 자동 제출
- 서술 자기 평가 보류, 주제별 결과·취약점·오답·진도·북마크
- 로컬 프로필별 IndexedDB 기록과 현재 사용자 JSON 백업·검증·합치기·덮어쓰기
- 왼쪽 메뉴 전체 접기·펼치기(상단 토글, 상태 유지), 독립 펼침 메뉴 10개, 모바일 메뉴·키보드·다크/라이트 테마

## 구조와 콘텐츠 관리

`src/content/*.json`은 UI에서 독립된 콘텐츠입니다. `engine.ts`는 채점·회차 구성, `storage.ts`는 트랜잭션·계정·백업, 페이지와 컴포넌트는 학습 화면을 담당합니다.

족보의 검토·작성 원본은 `scripts/build_past_bank.py`, 생성 데이터는 `src/content/past/bank.json`입니다. 작성 원본에는 비식별 문제·해설·출처 묶음만 포함하고 개인 자료를 읽거나 복사하지 않습니다. `python scripts/build_past_bank.py`로 재생성하고 `npm test`로 출처·중복·채점·Playfair/DES/DH 계산·백업 호환을 검사합니다. 미리보기 서버에서 `npm run test:past`는 4개 화면 폭의 문제집·한글 조합·자기 평가·5지선다·오답·백업을 확인합니다. 기존 은행의 IDs·회차·저장소 키는 유지합니다.

PPT 순서의 강의 본문은 `authoring/lecture_ch1.py`~`lecture_ch4.py`, 추가 예제는 `practice_support.json`, 문제·회차 빌더는 `authoring/build_content.py`입니다. 232개 본문 슬라이드의 설명 연결을 `slide-coverage.json`으로 검증합니다. 수정·보강은 이 원본에 반영하고 다음을 실행합니다. ID와 회차 배치는 고정되어 있습니다.

```sh
python authoring/build_content.py
python authoring/build_docs.py
npm run validate
npm run verify:content
```

원본 PPTX·변환 PDF·추출 원문·인증 DB·개인 기록·백업은 공개 저장소에 포함하지 않습니다. 기존 빅데이터 저장소는 수정하지 않았으며 검증된 화면·저장 로직 일부만 재사용했습니다.
